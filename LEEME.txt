PARA MI PAREJA - WEB ROMANTICA

Esta versión está preparada para GitHub Pages.

Archivos:
- index.html
- style.css
- script.js
- LEEME.txt

Para personalizar el mensaje:
1. Abre script.js.
2. Busca const text = `...`;
3. Cambia el texto por el que quieras.
4. Guarda y vuelve a subir el archivo a GitHub.

Para publicar:
- Sube index.html, style.css, script.js y LEEME.txt directamente a la raíz del repositorio.
- En GitHub Pages usa main + / (root).
